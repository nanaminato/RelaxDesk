# Shared office collector validation

Baseline `84bf9ef` on `codex/dxgi-media-pipeline`, stable .NET 11.0.100. The EXE collector and `Test-Office.cmd` had fallen behind source features. A single executable case factory now covers office functions for both developer DLLs and future self-contained EXEs. [Entry points, exclusions and bounds](../docs/OFFICE-ACCEPTANCE.md). No intermediate package is generated.

The source-only entry uses actual child applications, TLS, codecs, WPF, generated files and isolated clipboard/audio providers. It does not simulate process exit codes or replace production protocol/access checks. The suite contains 75 executable cases, including 2,036 Core/TLS assertions inside one case; a case count is not a count of individual assertions. It records the exact cases/exclusions and continues after independent failures.

First expanded suite: **74/74 PASS**, terminal exit 0, `build/office-collector-source-results/result.json`, summed child time 356.95s. The next 75-case review correctly returns **FAIL**, terminal exit 1: WPF reconnect times out waiting for connection end at `ReconnectVerification.cs:58`; all other cases continue. This was not waived or classified as an environment skip.

Review of the failure path exposed premature receiver-wide cancellation closing control before an independent terminal notice could arrive. Viewer now signals its first fault immediately, closes only its media reader during receiver cleanup, and gives transient media-read failure up to 300ms to finish the control task before global teardown. Other fatal stages do not wait. A test-only opaque relay delays control bytes by 150ms during explicit Host stop and checks that the delay actually occurred. Three full focused reconnect runs pass after the shutdown repair, followed by a passing run with the explicit delayed-notice fixture; three causal decode/submit/UI tests also pass. These observed terminal exits are 0 (`build/office-collector-reconnect-1.txt` through `-3.txt`, `build/office-collector-delayed-stop.txt`, `build/office-collector-causal-*.txt`). No packet trace of the earlier failing run is claimed.

Final Release build at `build/office-collector-complete-artifacts` passes with zero warnings/errors and unchanged native viewport DLL. Final source rerun is **75/75 PASS**, observed terminal exit 0, `PASS_SOURCE_AUTOMATION_ONLY`, summed child time 354.66s. It includes the deliberately delayed explicit-stop regression and all subsequent independent cases. [Final result](2026-11-24-office-collector-result.json). The shutdown repair is separately committed as `b24480a`; superseded initial failure logs have been removed.

Collector safety checks pass **48 assertions**, terminal exit 0 (`build/office-collector-delivery-contracts.txt` and final suite case): actual hash/optional length, legacy omission, Unicode path, malformed/oversized/count-bounded manifest, traversal/ADS/ambiguous/duplicate refusal, real junction sentinel, bounded capture/drain, actual small/overflow children and failed evidence writing despite child exit 0. Expected `overflow`/`unwritable` fixture rows are FAIL by design and required for the enclosing contract to pass. The new shared suite includes this contract. New self-contained EXE execution without a global SDK/runtime remains unaccepted because no bundle is produced.

PowerShell eligibility/classification/argument self-tests pass 11 checks each on PowerShell 7 and Windows PowerShell 5.1. `accept-home.ps1` raises the full graphics/WPF outer limit from 300s to a bounded 1,800s; the expanded runnable suite itself takes longer than the old budget. Script syntax and diff whitespace are checked. The physical template is updated to stop incorrectly calling already implemented rich clipboard/mouse/multi-monitor/audio unsupported, while retaining pending real-device results.

The optional `Collect-Logs.ps1` delegates integrity checking to the same EXE verifier instead of maintaining a weaker unbounded parser. Four actual PowerShell 5.1/7 delegation cases pass: valid fixture manifests return 0, wrong byte lengths return nonzero. These use a junction to the developer framework-dependent apphost and a one-file manifest fixture, not a new distributable or self-contained deployment proof (`build/collector-ps-delegation-9eb23fbadaea448ab25238ca76336808`).

Physical desktop capture/input/scanout, audible audio/sync, actual administrative service/boot/login/startup, final self-contained deployment, long soak, NIC/IP-loss and matched office/MSTSC performance remain unaccepted. Optional >1GiB copying and PowerShell installer tests retain their earlier separate evidence; they are not silently included in these 75 cases.
