# RelaxDesk 远程办公测试包（实验版，Windows x64）

本指南对应本目录 `package.json` 的版本与提交。请两端使用同一完整包，解压到新的可写本地目录；不要直接在 ZIP 中启动或只复制 EXE。随包包含 .NET 运行时，不需要 SDK、Visual Studio、Git 或 Python。程序未经代码签名；第三方声明见 `ThirdParty/`。RelaxDesk 尚未指定项目许可证。

当前是待真机验收的完整办公候选版。自动化通过不代表 Windows Home、可见桌面、真实输入、声音可听或办公性能通过。历史版本记录见仓库文档，不能据此判断当前包功能。

## 双机连接

1. Host 端双击 `Start-Host.cmd`，选择可信局域网的本机 IP、端口与共享屏幕。需要文件功能时，先选定一个专用共享目录，再开始共享。
2. Viewer 端双击 `Start-Viewer.cmd`，填写 Host IP 与端口；需要的剪贴板、文件和声音功能须在连接前单独请求。
3. Host 核对请求来源，按需勾选各项可选权限，点击允许。权限默认关闭；批准前不开放桌面与输入。拒绝不会共享。
4. 连接后将鼠标移至画面顶部中央的细条唤出工具栏。可进入文件、快捷键及其他功能，切换全屏或断开。工具栏移开后自动隐藏；本机预览不联网或发送输入。
5. Host 的“断开本次连接”结束当前控制并继续等待；“停止共享”或关闭 Host 窗口停止共享进程。每次重新连接都需新的授权。

普通 IP/端口连接采用首次接触信任，使用 TLS 和本次明确批准，但没有链外主机身份校验。只在可信局域网使用；需要预先验证身份时使用高级固定指纹方式。不会在固定指纹失败后降级。不要回传连接码、令牌、私钥或完整凭证窗口。

不需要管理员权限。不要关闭防火墙；仅按现有可信专用网络策略允许必要访问。默认不添加规则、服务或开机启动，也不改动 RDP、UAC 和系统策略。

## 日常操作

- 键盘、鼠标和远端输入法作用于共享的物理桌面。快捷键菜单可显式发送常用组合；安全注意序列 Ctrl+Alt+End / Ctrl+Alt+Del 不支持。需要本机输入法时打开“发送已完成的文字”，确认完成的内容后显式提交。
- 剪贴板的文字、图像、HTML 与文件分别受请求和批准约束。不会初次连接就读取旧剪贴板。Host 或 Viewer 可停止同步；重新启用需重新授权。文件剪贴板先显示提议并确认，在限定目录内传输，不等于对任意远端应用直接拖放。
- 文件面板支持浏览授权目录、上传/下载文件及目录、队列、进度/速率/ETA、暂停/继续/取消/重试，以及覆盖/保留两者/跳过。拖入文件先确认。路径链接和越界请求拒绝；完成前暂存并校验 SHA-256。意外中断后的续传只在限定时间、相同目录身份和新授权下经再次确认恢复；不承诺重启后续传。
- 显示器菜单仅列出 Host 授权范围，可切换单屏或全部屏幕。缩放提供适应窗口、1:1 和自定义比例/平移；插拔或变更后等待有效新画面再输入。新出现的屏幕不自动扩大授权。
- 声音只传输获准的系统输出，默认关闭；菜单可调音量、静音和停止。它不录制麦克风。真实可听、设备切换和音画同步须人工测试。
- 意外网络断开会在有界退避后尝试固定原主机身份重连，每次仍需 Host 同意；用户断开、明确拒绝和主机结束会停止重试。主机重启导致证书变化时不会静默接受。
- 工具栏持续标明 Host 帧报告的硬件/软件/图像兼容编码及 Viewer 实际 GPU/CPU 显示。GPU 显示不等于硬件解码；性能以测量为准。视频设置可调整 FPS 上限与 H.264 目标码率，实际结果见连接统计。目标值不保证实际交付率。
- 连接失败后可展开“最近一次错误详情”，查看、清除或复制阶段、异常类型/代码与本地关联标识。不会复制原始异常消息或凭证；复制异步执行，剪贴板繁忙时保留内容并提示重试。连接历史只在本次运行保留获准的 IP/端口，不保存秘密或权限。

锁屏、UAC 安全桌面、用户切换或会话失效可能结束共享。返回原用户普通桌面后重新连接与授权；本软件不承诺安全桌面控制，不切换到 SYSTEM，不支持无人值守授权。

## 自动检查与人工验收

`Test-Office.cmd` 校验完整性后运行共享办公合成检查，结果在 `logs/office-*/result.json`。通过仅标记 `PASS_PACKAGED_SYNTHETIC_OFFICE_ONLY`，不验证真实桌面、按键注入、物理显卡/驱动、真实声音或实际服务部署。

`Collect-Logs.cmd` 在已解锁的 Windows 10/11 Home 本地控制台运行；保持显示器连接、唤醒与测试窗口可见，不在 RDP 或会话 0 验收。它保存环境、哈希、分步 stdout/stderr、办公检查及满足独立显示门禁后实际执行的捕获/GPU/基准结果。失败或环境不适合时保留证据，不无限重试。结果在 `logs/home-*/result.json`，旁边有同名日志 ZIP；归档失败时保留该文件夹。

只校验包：`Tools\Smoke\RelaxDesk.Smoke.exe --collect-package . --verify-only`。
其他 Windows/RDP 诊断：`Tools\Smoke\RelaxDesk.Smoke.exe --collect-package . --diagnostic-only`，不能算 Home 验收。

最终人工逐项记录见 `docs/PHYSICAL-ACCEPTANCE.md`：两端版本与哈希、系统/显卡/驱动、显示器与 DPI/HDR、LAN 拓扑；真实画面、记事本/IDE/浏览器/Excel、中文/日文输入法、快捷键/五键鼠标、断线释放、各剪贴板格式、目录与大文件、重连/多屏、声音、长时间运行和安装。未做的项目写“未测”。性能须记录实际 FPS、带宽、CPU/GPU/内存及分布；提交/阶段耗时不等于 input-to-photon，不宣称 MSTSC 百分比。

回传 `logs/home-*.zip` 和双机人工记录，以及包名、ZIP SHA256、`package.json` 提交。日志含系统、驱动、会话、本地路径和性能；回传前检查隐私，不另附屏幕/输入/剪贴板内容或凭证。当前应用日志在 `%LOCALAPPDATA%\RelaxDesk\logs`，`host.log` / `viewer.log` 各最多 2MiB、另保留三份滚动备份；异步尽力写入可能丢失记录。两端关联 ID 不相同，可配合时间和阶段定位。

## 可选安装

便携运行即可。需要当前用户安装时双击 `Install-RelaxDesk.cmd`，安装到 `%LOCALAPPDATA%\Programs\RelaxDesk`，创建桌面/开始菜单入口与应用卸载项；不会默认启动共享或注册服务。升级前关闭该安装的应用；使用完整、未添加日志等文件的原始解压包，安装器会复核清单并拒绝修改过的源包。

从 Windows 应用列表卸载，或按 `docs/USER-INSTALL.md` 使用卸载脚本。未知/修改过的文件与独立日志会保留。可选当前用户登录入口必须显式选择，登录后只显示窗口，不开始共享。安装脚本遵循系统 PowerShell 执行策略，不绕过策略或解除下载阻止。

新版受控端可在“系统服务安装与协调（可选）”里选择启动方式，点击“安装／更新并启动服务（管理员）”或“卸载服务（管理员）”。先校验完整包并确认，再请求 Windows UAC；仅维护子进程提升权限，仍为原普通用户授权。共享运行中不可维护。完成后勾选服务协调并连接，不会自动开始共享。源码新增入口的验证边界见 `docs/SERVICE-SETUP-UI.md`；旧版本 ZIP 不会因此增加按钮。

机器级服务仅供单独的管理员部署验收：先阅读 `docs/MACHINE-SERVICE-INSTALL.md` 和 `docs/SESSION-BROKER.md`，在外部完整包目录运行 `Service\RelaxDesk.Service.exe --install-service --package . --owner-sid <目标普通用户SID> --what-if` 查看计划。实际安装去掉 `--what-if`；仅明确加 `--start` 才启动，默认手动启动，仅 `--automatic` 才设自动。程序不自行提权。服务不负责捕获/输入，仍须目标普通用户启动可见 HostShell、选择服务协调、开始共享并逐次批准。

卸载从外部包运行 `Service\RelaxDesk.Service.exe --uninstall-service --owner-sid <同一SID>`。`PendingDelete=true`/退出码2时保留文件，关闭相关服务管理句柄后重试；未知或修改文件保留并报告。真实 SCM、LocalService、开机/登录及安装升级均待操作者专门验收。

## 验证边界

源码及可执行合成检查覆盖协议/访问决定、TLS、故障与清理，不能代替 Home 双机。真实硬件、HDR/DPI、网络丢包、音频可听、管理员部署与长稳测试均需最终记录。麦克风、打印机、USB、摄像头与串口转发未实现。

包内 `docs/` 与 `benchmarks/` 提供合同、操作步骤及历史证据；日期和阶段限制必须保留，历史通过数不自动证明当前包或物理环境通过。哈希只检测完整性，不能替代从可信来源确认 ZIP 身份。
