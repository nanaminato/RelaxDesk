RelaxDesk 被控端（Windows x64，实验版）

1. 将整个 ZIP 解压到新的本地文件夹，双击“启动被控端.cmd”。不需要安装 .NET 或开发工具，不要只复制 EXE。
2. 从「连接」打开「设置登录信息」，从登录概要打开设置窗口，保存用户名与密码。用户名须为 6 至 64 个字符，密码须为 8 至 128 个字符。选择本机局域网 IP 后开始共享。
3. 首次连接时，连接端需要核对「登录设置」显示的 TLS 指纹。密码正确后，在受控端弹出的连接请求窗口核对设备指纹并批准。连接获准后，受控端按控制端请求提供剪贴板和声音。
4. 此后同一设备凭有效密码可直接连接，网络中断后也可免审批重连。可在「受信任的设备」撤销；改密码会清除原有设备授权。

批准连接后即可双向复制粘贴文件。用资源管理器选择文件并复制，在另一端准备完成后粘贴。远端文件操作遵循 Windows 当前登录账户的权限。普通桌面保持登录、解锁并在共享时可无人值守连接，锁屏、管理员窗口和 UAC 安全桌面仍需本机操作。

撤销信任会结束该设备的活动连接。「断开本次连接」只结束当前会话；「停止共享」关闭监听。

连接方使用单独的 RelaxDesk-Viewer-win-x64.zip。请使用本次发布的 Host 和 Viewer 配对。

这个包只含被控端、窗口与服务维护组件，不含连接端或开发验收工具。当前为便携运行包；「连接」页显示系统服务状态。点「设置系统服务」可跳到服务概要，再打开窗口启用或管理服务。完整性清单为 SHA256SUMS.json，版本为 package.json，第三方声明在 ThirdParty。

软件未经代码签名。真实 Windows Home 双机、服务部署、输入、声音与显卡表现仍需目标机器验收。
遇到问题请记录两端版本、操作和时间，并检查本机 %LOCALAPPDATA%\RelaxDesk\logs 中的日志；回传前检查隐私，不发送密码、私钥或私人屏幕/输入/剪贴板内容。
