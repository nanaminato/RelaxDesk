RelaxDesk 被控端（Windows x64，实验版）

1. 将整个 ZIP 解压到新的本地文件夹，双击“启动被控端.cmd”。不需要安装 .NET 或开发工具，不要只复制 EXE。
2. 选择本机局域网 IP，点击“开始共享”；把窗口中的 IP 和端口告诉连接端。
   开始前可将「允许的会话模式」设为「仅工作」，只接受 Work 及兼容旧版的工作连接。
3. 有人连接时，核对来源并点击允许。剪贴板、文件与声音权限分别按需允许，默认关闭。

需要系统服务时，点击“启用系统服务”，按 Windows 提示允许管理员授权即可。应用自动处理安装、启动和连接；已运行的服务不会重复提权。开机启动、修复和卸载在“更多设置”。无需查 SID 或输入命令。服务启用后仍需点击开始共享，不会自动批准连接。

普通局域网共享不要求先安装服务。使用可信网络，不要关闭防火墙或 UAC。停止共享或关闭窗口会结束本程序拥有的共享进程。

管理员窗口操作需要通过「系统服务」安装受保护的管理员输入代理，并由本机单独批准会话中的管理员申请和 Windows UAC。访客与工作模式可以在普通权限下使用。锁屏、登录及 UAC 安全桌面保留本机操作。

需要临时离开电脑时，可以在共享期间打开「受信任的工作设备」，选中已验证的设备，点击「预授权所选设备的下一次 Work 连接」，再核对指纹并确认。授权在 15 分钟内可用一次，范围为屏幕查看和普通桌面键鼠。使用后、手动取消、撤销设备、停止共享或收到 Windows 会话切换通知时，待用的预授权会失效。已开始的共享可用「断开本次连接」结束。

连接方使用单独的 RelaxDesk-Viewer-win-x64.zip，建议两端版本一致。工具栏中的文件、声音、多屏等功能仍受本次独立授权约束。文件仅访问你明确选择的目录。

这个包只含被控端、窗口与服务维护组件，不含连接端或开发验收工具。当前为便携运行包；系统服务可在窗口内选择安装。完整性清单为 SHA256SUMS.json，版本为 package.json，第三方声明在 ThirdParty。

软件未经代码签名。真实 Windows Home 双机、UAC/服务部署、输入、声音与显卡表现仍需目标机器验收；不代表安全桌面或无人值守控制已支持。
遇到问题请记录两端版本、操作和时间，并检查本机 %LOCALAPPDATA%\RelaxDesk\logs 中的日志；回传前检查隐私，不发送连接令牌、私钥或私人屏幕/输入/剪贴板内容。
