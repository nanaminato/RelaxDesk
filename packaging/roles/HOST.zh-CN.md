RelaxDesk 被控端（Windows x64，实验版）

1. 将整个 ZIP 解压到新的本地文件夹，双击“启动被控端.cmd”。不需要安装 .NET 或开发工具，不要只复制 EXE。
2. 在主界面点击「启用系统服务」，按 Windows 提示授权安装。组件需要维护时，通过「服务设置」更新或修复。
3. 选择本机局域网 IP，点击「开始共享」，将 IP 和端口告诉连接端。
4. 收到管理员输入组件显示的本机确认后，核对设备指纹并批准连接。本次连接可控制普通窗口及管理员窗口。代理就绪后开始共享。

剪贴板、声音和文件功能随连接启用。文件访问限于开始共享前在 Host 配置的目录。锁屏、登录和 UAC 安全桌面需要本机操作。

批准后可在「可信设备」中保存当前设备。每次连接仍需本机确认。撤销信任会结束该设备的活动连接，也可直接点击「断开本次连接」。

连接方使用单独的 RelaxDesk-Viewer-win-x64.zip。请使用本次发布的 Host 和 Viewer 配对。

这个包只含被控端、窗口与服务维护组件，不含连接端或开发验收工具。当前为便携运行包；系统服务可在窗口内选择安装。完整性清单为 SHA256SUMS.json，版本为 package.json，第三方声明在 ThirdParty。

软件未经代码签名。真实 Windows Home 双机、UAC/服务部署、输入、声音与显卡表现仍需目标机器验收；不代表安全桌面或无人值守控制已支持。
遇到问题请记录两端版本、操作和时间，并检查本机 %LOCALAPPDATA%\RelaxDesk\logs 中的日志；回传前检查隐私，不发送连接令牌、私钥或私人屏幕/输入/剪贴板内容。
