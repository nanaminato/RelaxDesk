# P2 办公体验与跨网

现状：已有多屏切换、缩放、IME、文本/图片/HTML/文件剪贴板、WASAPI 音频、独立 TLS 附属通道与文件恢复相关代码；已有 Tailscale/ZeroTier/frp 部署指南。不要重复开发文件浏览器或传输面板。

- 优先测大文件复制时输入/视频延迟、取消/恢复、剪贴板循环与资源上限；保持现有资源管理器复制粘贴 UX。
- 多屏先验证 DPI、坐标、热插拔、切换恢复，再评估独立编码和总预算；虚拟显示器驱动仅在无屏需求明确后研究签名、安装、卸载和恢复。
- 音频验证静音时是否停止无意义流量、缓冲上限、设备切换与弱网优先级；不让音频故障中断控制。
- 跨网优先完善现有 VPN/frp 诊断与 TCP 回退。若实际连接成功率不足，再设计可选 NAT 穿透、自建中继、身份绑定、端到端 TLS、限额与滥用防护；LAN 不依赖中心服务。
- 可参考 FreeRDP、TigerVNC、Xpra 的区域更新，Sunshine/Moonlight 的媒体管线，RustDesk 的会话设计，WebRTC/MsQuic 的网络机制。只研究设计，未选许可证前不复制第三方代码。

验收：并发文件/音频/视频、跨 DPI、断线重连、VPN/仅 TCP 转发与 UDP 不通场景；保留安全授权和回退，记录真实连接成功率、资源与操作延迟。
