# P1 Windows 会话与系统控制

现状：[SESSION-ACCESS](../SESSION-ACCESS.md) 记录 v5 全控制授权、普通权限协调器、Elevated Interactive Agent、LocalService broker。Default desktop 管理员窗口已有实现；UAC 安全桌面暂停，锁屏/会话切换结束授权。直接安全桌面控制、远程登录未实现。管理员角色不等于 SYSTEM。

先完成现有安装、真实 UAC 同意、管理员窗口输入、worker 崩溃与恢复验收；保留首次设备批准、密码、证书固定、设备撤销及单控制者语义。审计最新防爆破和抢占逻辑，未核实的行为不得写成已完成。
后续独立研究支持的 Windows API 与威胁模型：最小权限服务、正确交互会话 worker、受限 IPC、会话绑定与显式授权。不得禁用 UAC、修改安全策略、绕过登录、将整个 Host 提权或无提示扩大权限。安全桌面/锁屏/登录能力须另行批准设计，无法安全实现则保持暂停/结束。
验收：Home/Pro/Server 实机分别测环境变量、管理员终端、UAC、锁屏、登录、切换、注销、重启、断线按键释放、撤销、抢占竞态、安装升级卸载；记录实际权限与失败路径，未验证功能保持明确不可用。

## 2026-11-27 落地状态
- 已审计并运行通过 41 项 `SessionAdmissionChecks`（单控制者准入、防爆破速率限制、显式接管确认与抢占竞态、陈旧凭据拒绝）、52 项 `SessionAgentChecks`（最小权限 broker/session-agent 帧协议、身份绑定、租约、防重放、撤销与并发上限）以及管理员输入防重放与断线按键释放契约。
- 严格保持 v5 全控制授权、普通权限协调器、UAC 安全桌面暂停与锁屏/会话切换结束授权边界；不禁用 UAC、不修改系统策略；真实物理多版本 Windows 交互式 UAC/锁屏/重启验收保持显式标记。
