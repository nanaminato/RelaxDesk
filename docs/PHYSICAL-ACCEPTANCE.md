# 目标设备测试清单

本页供用户在空闲测试设备复测，不是已经通过的验收记录。准备本机操作者，使用测试文件和空白编辑器，出现卡键或失控时可从 Host 停止共享。

## 环境记录

记录两端版本/提交、包来源、OS、CPU/GPU/驱动、显示器/分辨率/刷新率、DPI/HDR、网络拓扑、传输模式及视频目标。Android 另记机型、系统、解码器和构建配置。

## 基本用例

| 项目 | 检查内容 |
| --- | --- |
| 首次连接 | 核对证书、拒绝错误密码、本机批准、拒绝或取消不会取得控制 |
| 再次连接 | 正确密码与设备信任生效，撤销后不能继续使用原授权 |
| 画面 | 静止、滚动、拖动和视频；缩放、多屏、DPI/HDR 单独记录 |
| 输入 | 键盘、输入法、鼠标与滚轮，断开后无卡键或旧输入重放 |
| 资源 | 启用所需剪贴板与声音，测试双向文件复制、完整性和静音 |
| 中断与接管 | 网络中断、明确接管、停止共享及重连，确认旧端不抢回 |
| 部署 | 当前用户安装/升级/卸载；可选服务的真实 UAC、SCM、登录/重启单独测试 |
| Android 生命周期 | 旋转、前后台、Surface 重建、断线后重连及长时温度 |

锁屏、UAC、管理员窗口、显卡设备丢失与跨账户服务是独立场景；普通桌面成功不能代替它们。

每项记录通过、失败或未测，附版本和复现步骤。性能采样按[比较方法](BENCHMARKS.md)和[弱网指南](WEAK-NETWORK-TESTING.md)执行；没有外部仪器时将物理 input-to-photon 标为未测。
