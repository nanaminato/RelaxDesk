# Android 显示与触控改进

第一批范围（2026-11-28）：推进 Phase 4 的 Android 比例适配及输入可靠性；完整硬件验收仍待真机完成。

## 行为约定

- 工具栏“显示”打开设置，提供适应、填充、原始像素。默认适应，切换模式恢复该模式的居中基准；独立“重置”只重置当前模式的缩放和平移。
- 适应完整显示视频并保留比例；填充等比裁剪并允许双指平移；原始像素将一个视频帧像素映射到一个 Android View 物理像素。若 Host 降采样，不代表主机桌面原始像素。
- 每种模式在基准上支持 1–4 倍捏合缩放；倍率提示显示相对当前模式的倍率，结束后淡出。平移始终限制在画面范围。
- 显示设置提供触控板灵敏度 0.50–3.00，默认 1.35，保存到本机。显示模式和视口变换仅对当前 Activity 生效。
- 单指直接触控进入双指操作前释放已按下的左键；多指结束前不恢复单指点击。取消、切换输入模式、进入后台及断开均清理手势状态与已按输入。
- 本批保留双指缩放和平移；双指滚动、轻点右键、双击拖动、自动平移、旋转选择、多显示器 UI 及直接输入法留待后续，避免手势语义冲突。

## 自动化验收

覆盖宽屏手机与平板比例、三种基准矩形、缩放焦点、平移边界、模式重置、坐标往返、多指转换与取消释放。运行 `dotnet run --project src/RelaxDesk.Android.Tests -c Release`；Android 构建使用 `dotnet build src/RelaxDesk.Android -c Release -p:SkipProbeAssetCheck=true`。

## 真机验收

连接真实 Host，分别在全面屏手机和平板检查：适应不裁剪；填充无黑边且能平移至四边；原始像素清晰且点击对齐；缩放时光标覆盖层与画面一致；重置不改变模式；倍率提示消失；灵敏度重启保留。直接触控按下后加入第二指、抬起一指再抬起全部，确认 Host 左键释放且无额外点击；取消、后台、断开和输入模式切换后无残留按键。记录设备、视频尺寸及结果。

本批不改变传输、编码或鉴权，不声称改善 FPS 或端到端延迟；未做物理性能测量。

真机观察（SM-S9380，用户报告）：填充模式最小倍率显示约 `1.0×`，在该倍率无法同时看到桌面的全部边缘。填充的 `1.0×` 以等比铺满手机视口为基准，比例不同时会裁剪画面。四边验收需分别双指平移到各边，确认每条边都能单独露出。用户随后确认可通过平移看到桌面边缘。后续补测结果见下。
