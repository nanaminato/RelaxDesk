# Windows 安装、升级与卸载

Host 与 Viewer 使用独立的 Windows x64 包：`RelaxDesk-Host-Setup-x64.exe` 和 `RelaxDesk-Viewer-Setup-x64.exe`。自包含安装包不要求目标机安装 .NET SDK；源码构建要求见[项目 README](../README.md)。

## 安装

1. 运行需要的角色安装器，按向导完成安装。默认目录为当前用户的 `%LOCALAPPDATA%\Programs\RelaxDesk\Host` 或 `Viewer`。
2. 从桌面或开始菜单打开对应应用。支持该功能的 Viewer 安装器还会注册 `rdesk`，可在 Win+R 中输入运行；便携 ZIP 不注册此命令。
3. 设置 Host 登录信息并开始共享，再由 Viewer 连接。首次设备需要 Host 本机批准，受信任设备仍需密码。

两个角色可并存、分别卸载。普通应用安装不自动安装系统服务、开启桌面共享或添加防火墙规则。系统服务由 Host 内的[服务设置](SERVICE-SETUP-UI.md)单独管理。

便携包请完整解压，使用角色启动入口，不要只复制 EXE。使用来源可信、版本匹配的两端程序，并检查发布包提供的版本与校验信息。

## 升级与卸载

关闭对应程序后安装新版本或重新安装。文件被占用、被修改或收据不匹配时先检查提示，不要强制覆盖未知文件。配置、设备信任、日志等数据与程序目录分开，卸载应用不意味着清空全部个人数据。

在 Windows“应用和功能”中按角色卸载。不再使用系统服务时，先在 Host 中明确卸载服务，再卸载 Host 应用；卸载普通应用不会代替机器级服务维护。

## 发行限制

当前仍为实验版，代码签名、SmartScreen、不同 Home 设备和真实服务部署需分别确认，不把安装器自动化当作完整发行验收。旧候选包路径、哈希和逐次安装记录已移除；历史版本可从 Git 历史追溯。
