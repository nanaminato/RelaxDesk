# 键盘、输入法与鼠标

Windows Viewer 中先点击远程桌面取得输入焦点。工具栏、菜单和本地对话框上的操作属于本机 UI，关闭后再回到远程画面。

## 键盘与输入法

普通按键与已完成文字提交是不同路径。需要本机输入法时，在会话工具栏使用文字提交入口，把完成后的文字发送到空白测试编辑器；不同应用对组合键与文字的处理可能不同。

没有反应时依次检查：Host 是否仍在共享、会话是否被接管、显示器切换是否完成、目标窗口是否有焦点。不要在密码框或生产终端里验证按键路由。

## 鼠标与触控

Windows 支持适应窗口、1:1 和自定义缩放；Android 支持直接触控与触控板模式。显示器、分辨率或旋转变化后先等新画面，再测试坐标。多屏、负坐标和混合 DPI 需在实际设备确认。

卡键或拖动未释放时，先松开本地按键并断开会话，由 Host 本机操作者检查。重连后不应重放旧输入。

## Windows 权限限制

普通权限 Host 的输入受 Windows UIPI 及桌面边界约束。管理员窗口、锁屏和 UAC 安全桌面可能无法控制；服务已启用不代表这些场景已获支持。保持本机操作者可用，不通过关闭安全策略解决。

提交输入问题时记录两端版本、布局/输入法、缩放、多屏配置和发生步骤。不要提交真实按键、密码或私人屏幕内容。见[排障指南](DIAGNOSTICS.md)。
